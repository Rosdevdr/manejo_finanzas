# Taste Skill (Anti-Slop Visual Design)

Based on `leonxlnx/taste-skill`. Replaces generic AI aesthetics with intentional, high-end agency visual design, editorial typography, controlled layout density, and modern motion principles.

## Active Sub-Skills

- `design-taste-frontend`: Comprehensive anti-slop guidelines for React, Next.js, and modern frontends. Covers framework standards, Tailwind v4, Motion (`motion/react`), color theory, visual hierarchy, responsive layout, and pre-flight quality checks.
- `high-end-visual-design`: Agency-level typography pairings, exact spacing scales, elevation/shadow formulas, card containers, and luxury layout structures.

## Core Rules

1. **No AI Slop Defaults**: Avoid purple-to-blue gradient headers, generic rounded card grids with identical box-shadows, centered generic hero copy, and low-contrast grey text.
2. **Typography Discipline**: Strict hierarchy. Display fonts for heroes, neutral geometric sans for body, tabular figures for finance (`font-variant-numeric: tabular-nums`).
3. **Restraint & Elevation**: Use border glows, subtle glass highlights (`rgba(255,255,255,0.06)`), and deep obsidian backgrounds (`#0a0b0e`) instead of harsh pure black or washed out gray.
4. **Motion with Purpose**: 150-250ms snappy cubic-beziers or physics springs (`stiffness: 400, damping: 30`). No sluggish 500ms ease-in-out animations.
