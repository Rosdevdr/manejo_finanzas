# Claude SEO Suite

Comprehensive SEO analysis and implementation suite for web applications and digital platforms.

## Core Capabilities & Playbooks

- `seo`: Orchestrator for full site audits, business type detection, GEO/AI search optimization (ChatGPT, Perplexity, Google SGE), Core Web Vitals, and indexability.
- `seo-audit`: Full website crawl analysis, delegation to 15 specialist checks, and automated health score generation.
- `seo-technical`: 9-category technical audit: robots.txt, sitemap XML, canonical tags, HTTPS, URL structure, Core Web Vitals (LCP, FID/INP, CLS), and server headers.
- `seo-schema`: Schema.org structured data generator and validator (JSON-LD format: Organization, WebSite, SoftwareApplication, FinancialProduct, FAQPage, BreadcrumbList).
- `seo-content`: Content quality assessment, E-E-A-T trust signals, readability scoring, and AI watermarking cleanup.
- `seo-page`: Single URL / single page deep audit covering meta tags, headings (single H1, hierarchical H2-H6), image ALT text, and OpenGraph/Twitter social cards.
